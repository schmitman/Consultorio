## Publicar en Cloudflare Pages
1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → elegir este repo.
2. Framework preset: None. Build command: (vacío). Output directory: `/`.
3. Custom domains → agregar el dominio.
